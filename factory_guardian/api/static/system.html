證據不足繼續觀察並重新診斷，不急著動設備。

Decision boundary

LLM 負責解釋，不握方向盤

所有會改變設備狀態的決定，都由可重現的數值方法、規則引擎與核准流程控制。

自主不代表無人負責

系統把責任邊界寫進流程，讓每個動作都能回答：根據什麼、誰核准、做了什麼、結果如何。

政策閘門在執行之前，驗證閘門在執行之後

安全 Agent 與 Policy Engine 可以阻擋任何不符合 SOP 的方案。高風險動作保留人工核准，執行後還要量測結果，失敗就停止自動流程。

ALLOW低風險且符合所有安全規則，可以執行。
APPROVAL高風險動作等待具名操作員核准。
BLOCK違反硬性規則，直接從候選方案移除。

Audit evidence

每個結論附來源感測器、手冊、歷史案例、視覺、拓撲或規則。
每個分數可重算權重、門檻、候選方案與投影結果都保留。
每個動作可追責政策裁決、核准人、執行效果與驗證結果完整記錄。
