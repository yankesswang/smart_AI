The local derivative was resized to 960×540, color-adjusted, stripped of audio,
and compressed for offline demo use. It is used only as illustrative monitor
footage. The UI permanently labels it “DEMO FOOTAGE / NOT LIVE” and
“SYNTHETIC VISION EVENTS”; it is not represented as a real camera stream or as
input actually analyzed by the demo's Vision Agent.

## Hazard-zone event clip

- Local files: `factory-cctv-hazard-demo.mp4`, `factory-cctv-hazard-demo.webm`
- Original title: **Industrial Factory Workers Operating Machinery**
- Contributor: **Usman AbdulrasheedGambo**
- Source: https://www.pexels.com/video/industrial-factory-workers-operating-machinery-32243444/
- Original download: https://www.pexels.com/download/video/32243444
- Source page marking: **Free to use**
- License reference: https://www.pexels.com/legal-pages/license/
- Retrieved: 2026-08-13

The local derivative was resized to 960×540, reduced from 50 to 24 fps,
color-adjusted, stripped of metadata/audio, and compressed. It is selected only
when the synthetic camera state reports a hazard-zone or PPE event. The workers
wear hard hats; the demo therefore labels the PPE event specifically as missing
high-visibility clothing (`NO HI-VIS`), not as a missing helmet. A fixed
scenario overlay marks one worker and the restricted area. This is
event-matched stock footage, not footage actually analyzed by the model.
MP4/H.264 and WebM/VP9 variants are bundled so Chromium, Chrome, Firefox,
Edge, and Safari can choose a codec they support without network access.
