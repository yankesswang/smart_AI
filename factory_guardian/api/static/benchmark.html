同一座工廠

四組跑在相同亂數種子、相同故障情境、相同總模擬時長的數位孿生工廠上， 差別只有「AI 做到哪一步」。所有數字都是模擬器實際執行產生的結果，不是預錄，也不是估算。 每次重跑都會得到同一組數字，這正是可重現性的意義。

A 固定門檻告警
感測器踩到危險門檻就發告警，之後什麼都不做。這是「告警完全沒被接住」的極端。
B 偵測即停機
偵測到異常立刻停機維修，技師零等待。設備保住了，但沒有影響分析與替代排程。
C 現行流程
告警 → 人工判定根因 90 分鐘（機台照跑、照劣化）→ 停機維修 → 復機。不轉單。 A 和 B 都是極端，沒有工廠長那樣 —— C 才是該被比較的對象。
