這些配置如何影響 Agent？

同一個 M-A 異常，處置方案會沿著產線關係影響訂單、下游與安全決策。

M-A 發生異常

振動、溫度或工安事件超出可接受範圍。

→
比較處置方案

繼續降速、停機維修，或把 P-100 訂單轉到 M-B。

→
驗證整線結果

確認 M-A 安全、M-B 排程可行，且 M-C 沒有缺料。

Diagnosis Agent用 M-A 感測器與設備手冊判斷根因。
Impact Agent沿產品路徑計算訂單與 M-C 的下游影響。
Planning Agent把 M-B 換線與既有 P-200 排程放進模擬。
