# 一、2026 競賽規則總整理

## 1.1 先回答前面三個問題

| **問題** | **官方規定與判讀** |
| --- | --- |
| 社會組可以一人參賽嗎？ | 可以。官方規定每隊 1–6 人；社會組包含社會人士、一般個人、新創團隊、企業組織及相關產業人士。團隊至少一人須具中華民國（臺灣）國籍。 |
| 可以投多件嗎？ | 可以。每件作品須分開報名；同一參賽者若有多件達到決賽門檻，只取分數最高的一件進入決賽。 |
| 投稿件數有上限嗎？ | 截至 2026 年 8 月 12 日，官方競賽辦法只寫『可多件投稿』，未明列件數上限。若計畫大量投稿，仍建議先向執行單位確認報名系統或帳號是否有操作限制。 |

*來源：2026 官方競賽頁面與競賽辦法〔S1、S2〕。*

## 1.2 參賽定位與資格

| **項目** | **規定** |
| --- | --- |
| 年度主軸 | 智慧驅動、數位韌性、永續未來 |
| 校園組 | 在校學生或應屆畢業學生，可跨校、跨年級組隊；指導老師至多 2 位。 |
| 社會組 | 社會人士、一般個人、新創團隊、企業組織、相關產業人士。 |
| 隊伍人數 | 每隊 1–6 人；至少一位具臺灣國籍；需指定一名團隊代表人。 |
| 跨身分組隊 | 學生可與社會人士混合組隊，但只能報名社會組。 |
| 未成年人 | 報名截止日前未滿 18 歲者，須附法定代理人同意書。 |
| 團隊變更 | 報名截止後不得更換隊員或更新參賽文件。 |
| 舊作限制 | 2022–2025 年本賽事得獎作品不得參加 2026 年賽事。 |

## 1.3 八大智慧主題

| **主題** | **官方方向摘要** |

| 智慧文化 | 文化科技、藝術展演、策展行銷、觀光導覽、體育、數位學習；可用生成式 AI、XR、數位孿生。 |
| 智慧製造 | 機聯網監控、產線戰情、生產／能源管理、AI 視覺檢測、工安、預測維護、遠距協作。 |

| 智慧通信 | 海地星空網路結合 AI；防災通訊、網路品質優化與通信加值服務。 |

> **FactoryGuardian 最適合的主題**
>
> 首選「智慧製造」。官方方向直接列出工安管控、設備預測維護、機聯網、戰情中心與遠距專家協作；若再加入節能或工廠減碳，可在永續分數上形成輔助，但不要為跨類別而擴張功能。

## 1.4 報名文件與格式

| **文件／規格** | **要求** |
| --- | --- |
| 身分證明 | 必繳；社會組身分證、校園組學生證。 |
| 參賽同意書 | 必繳；使用官方表單。 |
| 作品提案規劃書 | 必繳；A4、Word 或 PDF、需標頁碼、字體不得小於 12 pt、檔案不超過 20 MB。 |
| 建議篇幅 | 15 頁以內；不含封面、封底、目錄與參考書目。 |
| 必要內容 | 作品主題、特色、設計理念、使用情境、商業模式、預期成果、開發工具及相關說明。 |
| 介紹影片 | 選填；非必要，但官方建議提供以協助評審理解。 |

## 1.5 評分標準與競賽含義

| **初賽項目** | **比重** | **評分重點** |
| --- | --- | --- |
| 創新與技術性 | 30% | 創新性；應用 AI 等前瞻技術。 |
| 商業價值與市場性 | 30% | 商業可行性與市場需求。 |
| 業務連結性 | 20% | 可與中華電信業務結合並具發展潛力。 |
| 整體表現與用戶體驗 | 20% | 介面、設計、可行性與便利性。 |

| **決賽項目** | **比重** | **評分重點** |
| --- | --- | --- |
| 技術成熟度 | 40% | 完整度、產品生命持續性、未來擴充性。 |
| 商業價值與市場性 | 40% | 商轉可能、商業模式、競爭力。 |
| 業務可落地性 | 10% | 可直接與中華電信合作或應用。 |
| 永續發展性 | 10% | 符合數位永續發展趨勢。 |

> **最重要的評分訊號**
>
> 決賽有 80% 集中在「技術成熟度＋商業價值與市場性」。單純概念、只有聊天介面、沒有量化成效或不穩定的 Demo，很難靠題目新穎度補回差距。

## 1.7 容易忽略的限制

- 參賽作品及提案、簡報須為原創；引用他人智慧財產須取得書面同意。
- 決賽所用伺服器、作業系統與軟體須具合法授權；網路資安由隊伍自行負責。
- 若決賽前作品已與中華電信合作上架，或隊伍為相關專案合作廠商，主辦單位有權取消資格。
- 主辦單位具有與決賽作品優先洽談合作或商轉的權利。
- 獎項可由評審決議從缺；規則可能更新，送件前應再核對官網最新版本。

# 四、FactoryGuardian 題目診斷與建議方案

## 4.1 建議定位

> **題目名稱**
>
> FactoryGuardian｜可稽核的多模態工廠異常處置 Agent

> **一句話價值主張**
>
> 整合設備感測、機器聲音、現場影像、維修手冊與歷史工單，主動找出異常根因，提出有證據的處置方案，經人員確認後派發工單，並自動驗證設備是否恢復正常。

## 4.2 為什麼目前方向有機會

| **面向** | **判讀** |
| --- | --- |
| 題目與官方主題 | 高度符合智慧製造列出的機聯網、設備預測維護、工安與遠距專家協作。 |
| 歷屆趨勢 | 製造、巡檢、維護與工安持續得獎，顯示痛點強、買方明確、商業價值容易量化。 |
| 差異化空間 | 歷屆多集中在單點檢測或設備方案；你的機會是做『多模態證據＋根因＋人工核准＋工單＋修復驗證』。 |
| 中華電信連結 | 可自然結合 5G 專網、MEC、hicloud AI、OT 資安與定位，不必硬套技術。 |

## 4.3 必須收斂的範圍

> **核心風險：功能過多**
>
> 若同時包含維修 Copilot、生產異常、工安、排程、採購、數位孿生與自動控制，會變成『功能集合』而非一個能完整驗證的產品。建議只鎖定一種工廠、一台關鍵設備與一種高價值事故。

| **收斂維度** | **建議** |
| --- | --- |
| 場域 | 例如化工廠／食品廠／電子組裝廠，擇一。 |
| 設備 | 例如泵浦、風機、馬達或空壓機，擇一。 |
| 事故 | 例如軸承異常＋溫升＋洩漏風險，形成單一可重現劇本。 |
| 決策 | 先降載／隔離／安排檢查，由主管核准後執行。 |
| 成果 | 縮短異常發現與處置時間，降低非計畫停機與工安風險。 |

## 4.4 五個真正的差異化

- 多模態：同步使用感測訊號、機器聲音、現場影像、SOP 與工單歷史。
- 根因導向：從『有異常』進一步推到可能原因、替代假設與處置順序。
- 可稽核：每個判斷附資料時間點、影像、手冊條款、相似工單與信心分數。
- 人工在環：高風險動作需由具權限人員核准，並留下審批紀錄。
- 閉環驗證：偵測 → 診斷 → 核准 → 工單 → 維修 → 訊號恢復 → 事件結案。
## 4.5 與歷屆作品的重疊與避讓

| **歷屆作品** | **可能重疊** | **你的避讓方式** |
| --- | --- | --- |
| 2024 AI 智慧刀把 | 預測磨耗／剩餘壽命 | 不要只做單一設備預測；強調多模態根因、工單閉環與可稽核證據。 |
| 2024 紙漿智慧製造 | 5G 專網、AI、IoT、產線與工安監控 | 不要做泛用戰情中心；聚焦一個異常處置流程與量化成效。 |
| 2022 數位孿生 AI 檢測 | 虛實同步、遠端機台 | 數位孿生只當選配，不要成為主敘事。 |

| 2025 無所遁形 | 不中斷偵測電氣異常 | 避免把題目縮成單一電氣放電偵測；明確切換到設備根因與處置閉環。 |

## 4.6 建議的產品流程

1. 持續接收振動、溫度、電流、聲音與影像。
2. 邊緣模型偵測異常並保留異常前後時間窗。
3. Agent 讀取維修手冊、SOP 與相似歷史工單。
4. 輸出根因排名、證據、信心分數、替代假設與風險等級。
5. 提出可執行的處置方案；高風險動作要求人工核准。
6. 核准後自動建立工單、指派人員並追蹤處理。
7. 維修後重新檢查感測訊號與影像，判定是否恢復。
8. 生成事件報告，回寫處置結果供後續模型與 SOP 改進。
