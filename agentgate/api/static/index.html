六個步驟走完治理閉環

正常放行 → 分級核准 → 注入攔截 → A/B 對照 → 稽核回溯 → 量化成效。點左側任一步驟執行；每一步都會顯示指令走到哪一道關卡、被誰擋下、依據哪一條規則。

動作請求由誰產生 —

切到「真 LLM Agent」後，步驟 2／3／4 會把整件工單（含附件全文、夾帶的那一行） 送進模型，由模型自己決定要呼叫哪個後台工具。來源鏈不由模型自報， 而是由 agent runtime 依「模型讀進 context 的東西」組出。沒有金鑰時會誠實顯示降級。

Tamper-evident audit chain · G5

稽核鏈

每筆紀錄含前一筆的雜湊。被擋下的動作與被執行的動作留下同等完整的紀錄 —— 這是稽核完整率能到 100% 的原因。竄改任何一筆,驗證當場失敗並指出斷點。

竄改演示會偷改鏈中一筆紀錄的內容,不改雜湊 —— 用來證明「改得掉資料,改不掉鏈」。
