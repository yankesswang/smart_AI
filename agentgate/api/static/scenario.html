05人卡在哪一段

低風險自動走完,高風險停在人手上。停多久也是政策的一部分。

核准時限:風險越高、時限越短
高5 分鐘 · 批次匯出 / 停話 / 補發 SIM
中15 分鐘 · 退費 / 變更資費
低30 分鐘 · 被改判為需核准的動作
條長＝可用時間。三班主管輪值,核准者身分綁門號級憑證 —— 推播可轉發,SIM 不行。
